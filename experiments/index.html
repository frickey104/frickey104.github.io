実験室INTERACTIVE EXPERIMENTS

ブラウザで動く、触れるものをつくっています。触った跡が作品に残り、次の挙動を変える—— そういう仕掛けが主な関心です。

ここに並ぶのは完成品ではなく実験です。各項に「試したこと」と「転んだところ」を添えています。 うまくいった話より、そちらのほうが残す価値があると思っているからです。

  1. 実験 #01

    🌬 風の地形

    Perlin ノイズの流れ場を粒子が流れる。マウスの軌跡が「地形」として場に残り、 後から来る粒の流れを変える（減衰 0.99994/frame）。

    転んだところ
    setPointerCapture を状態の初期化より先に呼んでいた。例外が飛ぶと線が無言で壊れる。 「4本描いたのに1本しか記録されない」で発覚。先に状態を作り、捕捉は try/catch に。
    まだ転んでいるところ
    窓の大きさを変えると、彫った地形が薄くなる。ux/uy をセル添字でコピーしていて 「引き継いでいる」つもりだったが、彫った点の明度比を測ると 2.45→1.41 に落ちた。 リサイズしなければ同じ時間で 2.40→3.91 と逆に濃くなるので、引き継ぎ切れていない。 直していない——リサイズは「作品を保つ操作」なのか「作り直す操作」なのか、まだ決めていないので。

  2. 実験 #02

    🦠 侵食するもの

    Gray-Scott 反応拡散を WebGL2 で。RGBA16F の ping-pong で 26 steps/frame。 撒いた種が自己増殖して広がり、増えたものは戻らない。模様5種。

    転んだところ
    遅すぎて静止して見えた。止まっているのか遅いのか区別できず、点灯画素を数えたら 2.5秒で 658→714 と増えていた——動いてはいた。steps 12→26、初期種 5→9 個に。 「見た目で止まっている」と「実際に止まっている」は別物だった。

  3. 実験 #03

    💎 割れる

    ヴォロノイ図を半平面クリッピング（Sutherland–Hodgman）で実ポリゴンに落とし、 破片として剛体落下させる。叩くほど細かく砕ける。

    転んだところ
    隣り合うセルの明度が近すぎて、面ではなくワイヤーフレームに見えた。 重心のハッシュでセルごとに明度と彩度をばらし、ファセットとして立たせた。
    まだ転んでいるところ
    窓の大きさを変えると、割った跡が全部消えて別の割れ方になる。 resize() が reset() を呼んでいて、種を撒き直しているため。 リサイズ前後の画像相関は 0.07（＝無相関）。4本の中でこれが一番はっきり消える。 直していない——「割り直す」のもこの作品らしい、という判断で置いてある。

  4. 実験 #04

    🔊 描くと鳴る

    Web Audio。線1本が1声に対応する（ペンタトニック・合成IRリバーブ）。 本数が増えると音量を 1/√n で割り、重ねても飽和しないようにしている。

    転んだところ（4本共通）
    起動時にウィンドウが非表示だと 0×0 で初期化され、以後なにも描かれない。 しかもエラーは出ない。最小サイズを保証し、実サイズがついたら作り直す自己修復を全4本に入れた。
    まだ転んでいるところ
    窓を狭めると、描いた線が消える。広げるぶんには無事（点灯画素 32,992→46,130）だが、 狭めると 0 になった。線を device px の絶対座標で持っているので、 新しい画面の外に出たものは戻ってこない。放置すれば線は残る（5秒で 33,788→28,145）ので、 消しているのは時間ではなく縮小のほう。直していない。
