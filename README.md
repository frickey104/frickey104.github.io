# frickey の工房（2026-10-26_portfolio）

ゲームと道具と小物をまとめた作品集のサイト。https://frickey104.github.io/

- 作品の元のファイルは、それぞれのフォルダの `index.html`。このサイトにはその写しを置く
- 作り直し方: `python build.py` で、作品の写し（`<slug>/index.html`）・サムネイル・X のカード画像・トップページを作り直し、公開前の点検をする。最後の行が `ok` なら上げてよい
- 載せる作品: 開いて動く作品は全部載せる。載せる作品は `build.py` の `ITEMS`（外のものは `EXTERNAL`）に書く。載せない作品は書かない（写しや画像が残っていると点検が ng になるので消す）
  - 新しく足すときは、作品の画面を幅 800 で撮って `drafts/shots/<slug>.jpg` に置き、`ITEMS` に1行足す（`crop` はその写真の中のサムネイルにする範囲）
- 状態（完成・途中・止めた）: `works\README.md` の表の「状態」の列の頭の語を読む。`build.py` では書かない。読めない作品があると ng
  - カードの左上のラベル: 完成＝緑・途中＝黄・止めた＝灰。途中のカードには「試作◯版・更新日」（更新日は作品フォルダの git の最新 commit の日）
- トップの並び（`build.py` が作る）: 自己紹介と「今週の変化」（直近7日に作品フォルダの git が更新された作品・最大3つ）→ すぐ遊べる（完成で `pick=True` の2〜3本）→ ほかの完成品 → 作りかけの棚（途中）→ つくったもの（`thing=True`）→ 止めたもの。点数と「◯◯ 更新」の日付は組み立てた日に自動で変わる
- 点検（`build.py` の `check()`）: 個人の情報の言葉（HTML のコメントも）・外への読み込み（Google Fonts だけ）・画像の撮影情報（Exif）・PNG の文字の情報（tEXt/iTXt/zTXt。埋め込みの画像も）・`drafts/` のファイルや `.stl` が混じっていないか
- 中身:
  - `index.html` — トップページ（`build.py` が `_top.html` から作る）
  - `_top.html` — トップページの元（頭・見た目・作り方の欄。カードは書かない。`_` で始まるので公開されない）
  - `<slug>/index.html` — 作品の写し（`build.py` が作る。手で直さない）
  - `img/` — サムネイルと X のカード画像（`build.py` が作る）
  - `build.py` — 組み立てと点検
  - `drafts/` — 画面の写真（`shots/`）と下書き（上げない）
