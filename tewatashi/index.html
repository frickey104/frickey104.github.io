てわたし相手が選んだ駒を置く 2人対戦

　

　

渡せる駒

色: 白木 / くるみ大きさ: 大 / 小形: 丸 / 四角中: 穴 / なし
遊び方
  1. 駒は16個。4つの特徴（色・大きさ・形・穴）の組み合わせが全部ちがう
  2. 自分の番は「置く」→「渡す」の順。置くのは相手が選んで渡してきた駒。置いたら、残りから相手に置かせる駒を選んで渡す
  3. 縦・横・ななめに4つ並んで、どれか1つの特徴が全部同じなら、その駒を置いた人の勝ち（どちらの人が置いた駒でもよい）
  4. 盤が埋まって誰もそろえられなければ引き分け。「2×2 も勝ち」にすると、小さな正方形の4マスでもそろう

渡せる駒のうち薄く見えるものは、渡すと相手がすぐ勝てる駒。最初は見えている方が分かりやすいので表示している。
